Nav atual do CitraChat vai ganhar um dropdown "Soluções" (próxima fase).

**Por quê:** Bruno identificou que o diferencial do CitraChat é a especialização por objetivo do agente. Cada tipo de agente merece uma página dedicada com copy e argumentação próprias — não é só segmentação de público, é posicionamento por caso de uso.

**Estrutura planejada:**
- `/solucoes/captacao-de-leads` — foco em qualificação + pixel tracking
- `/solucoes/sac` — foco em resolução rápida + protocolo automático (já existe em `/atendimento`, vai migrar)
- `/solucoes/suporte` — foco em base de conhecimento + handoff
- `/solucoes/recepcao` — foco em triagem + multi-agente
- `/solucoes/atendimento` — genérico / overview (ou redireciona pra SAC)

**Home:** após as páginas de Soluções estarem prontas, adicionar seção na home cobrindo todos os tipos de agente.

**Status:** roadmap registrado em 2026-09-01. Ainda não implementado.

**How to apply:** quando Bruno disser "vamos fazer as páginas de Soluções" ou "adicionar dropdown no nav", retomar este roadmap. Antes de implementar, confirmar quais slugs e quais páginas existentes reutilizar.
