Descrições e legendas de posts NÃO devem recapitular o conteúdo dos slides.

**Why:** A descrição que reconta o post elimina a razão de o usuário arrastar e ler. Perde a curiosidade, perde o engajamento, perde o comentário.

**How to apply:** A descrição deve criar tensão, fazer uma pergunta provocadora, soltar um dado isolado que gera "como assim?", ou introduzir o tema de forma que o post seja a resposta — não a descrição. Informação sim, recontar não. O post é o destino, a descrição é o convite.
