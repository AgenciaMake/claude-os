Na abertura do briefing, Alfred deve mencionar o serviço contratado usando o nome simplificado do produto Make, não uma lista de serviços individuais.

**Produtos Make válidos:**
- Make Performance
- Make Social
- Make Dev
- Make 360º

**Why:** Ficar listando cada serviço contratado é redundante e pouco elegante. Alfred deve citar o nome do produto Make (Make Performance, Make Social, Make Dev, Make 360º). Se o contrato tiver fases, citar as fases brevemente.

**How to apply:** Ao gerar ou revisar o prompt do Alfred, verificar que a abertura menciona o produto Make, não uma lista de serviços individuais.

**Exemplos:**

Errado:
> "Estou aqui para ajudar com gestão de tráfego pago, criação de criativos e relatórios mensais."

Certo:
> "Estou aqui para ajudar com o Make Performance."

Com fases:
> "Estou aqui para ajudar com o projeto que tem duas fases: Fase 1 é a construção do site (Make Dev), e Fase 2 é Make Performance."
